# AI usage

This implementation was authored with AI assistance and reviewed by a human for tenant scoping, validation, transactional booking behavior, and frontend accessibility. AI-assisted tasks included adding regression coverage, replacing an incorrect Okta browser-auth integration with the official Auth0 React SDK, configuring Auth0 PKCE token handling, and tightening persisted assignment display. No credentials or production data were used. Final validation includes the project test/build commands documented in the repository; external Auth0 login requires evaluator-provided SPA configuration.
